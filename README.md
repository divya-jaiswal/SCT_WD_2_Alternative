# Calculator Web Application

A simple and fully functional calculator built using HTML, CSS, and JavaScript.  
This project was developed as part of **Internship Task 02 (Alternative)** to practice DOM manipulation and event handling.

---

## 🚀 Features
- Basic arithmetic operations (+, −, ×, ÷)
- Clear and delete functionality
- Keyboard input support
- Error handling for invalid expressions
- Responsive and clean UI

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 How It Works
- User inputs numbers using buttons or keyboard.
- JavaScript updates the display dynamically using DOM manipulation.
- Expressions are evaluated when the equals button or Enter key is pressed.
- Errors are handled gracefully using try–catch blocks.
